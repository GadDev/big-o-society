# Curriculum

The Society does not grind random problems. It builds pattern recognition deliberately.

<PatternCallout label="THE RULE" tone="memory">
Before you write code, complete this sentence:

**“I think this is ___ because ___.”**
</PatternCallout>

## Daily ritual

1. **Recall — 2 min:** explain yesterday’s pattern without looking.
2. **Recognize — 5 min:** identify the pattern before coding.
3. **Implement — 20 min:** solve it from scratch.
4. **Test — 5 min:** make Vitest green and attack edge cases.
5. **Explain — 5 min:** state why it works and give time/space complexity.
6. **Remember — 2 min:** keep one trigger phrase.

## Progression

- **Level 1:** recognize the pattern.
- **Level 2:** implement without notes.
- **Level 3:** explain the invariant.
- **Level 4:** adapt it to an unfamiliar problem.
- **Level 5:** combine patterns.
