# DSA Pattern Refresh Library

Use these chapters **before** tackling an exercise. Keep the refresh short: roughly 5–10 minutes.

## Recommended ritual

1. Look at the illustration for 30 seconds.
2. Say the memory trigger aloud.
3. Read the recognition questions.
4. Explain the invariant without looking.
5. Close the chapter and solve the exercise.
